# ryanio.github.io

Redirects https://ryanio.github.io/ to [ryanio.com](https://ryanio.com/). Project sites keep their own paths: [PFP Census](https://ryanio.github.io/pfp-census/) and [Card Census](https://ryanio.github.io/card-census/).

There is no custom domain on this repo on purpose. Setting one would move every project site under that domain.
